# 📡 科技前沿简报 — 全自动 AI 科技新闻日报

> 每天早晨 8:30，一份「穿透 PR 表面、只留结构性变化」的科技前沿速报，自动推送到你的飞书和邮箱。

**RSS 采集 → 大模型苏格拉底式筛选 → 多维去重 → 精美简报 → 飞书/邮件/PDF 全链路自动化，跑在 GitHub Actions 上，零服务器、零成本。**

---

## ✨ 它解决了什么问题

科技新闻浩如烟海，但绝大多数是 PR 稿、软文、和「宏大愿景」。读 100 条流媒体推送，不如读 5 条真正重要的。

这个项目用**苏格拉底式追问**穿透噪音，每天只交付 **5 条**最值得关注的产业重磅：

- 🎯 **穿透表面** — 剥掉所有 PR 形容词，只看「谁做了什么、产生了什么可验证的结果」
- 🏰 **追问护城河** — 是否改变了竞争壁垒？常规迭代不给高分
- ⏳ **时间尺度检验** — 3 个月后还会被人提起吗？当天热闹要降权

## 🧠 苏格拉底式筛选（核心亮点）

这不是简单的「按热度排序」，而是模拟一个**极度怀疑的产业洞察者**的思考过程：

```
穿透表面：去掉「生态系统」「全面赋能」这些空洞话术
   ↓
追问护城河：这个「突破」竞争对手多久能复制？是转折点还是噪音？
   ↓
时间尺度检验：3 个月后还会有人讨论它吗？
```

**实际效果对比**（真实案例）：

- ❌ **创业公司 PR 稿**：「XX 发布模型，三段范式全部落位」— 满屏漂亮话，被降权
- ✅ **头部公司硬新闻**：「Figure AI 公布 56% 成功率，同行激烈质疑」— 有硬数据、有争议、有产业意义，入选

## 🛠️ 技术栈

- **Python** — 单文件核心逻辑，清晰可维护
- **RSS / Atom / JSON** — 三种 feed 格式统一解析（含命名空间处理）
- **SiliconFlow / DeepSeek** — 免费大模型 API 打分
- **GitHub Actions** — 定时调度，零服务器
- **飞书 Webhook + Resend** — 消息推送

## 📦 快速开始

### 1. Fork 本仓库，配置 Secrets

在仓库 `Settings → Secrets and variables → Actions` 配置：

| Secret | 说明 |
|--------|------|
| `ANTHROPIC_AUTH_TOKEN` | 大模型 API Key（SiliconFlow 免费） |
| `ANTHROPIC_BASE_URL` | API 地址，如 `https://api.siliconflow.cn` |
| `LLM_MODEL` | 模型名，如 `Pro/deepseek-ai/DeepSeek-V3.2` |
| `RESEND_API_KEY` | Resend 邮件 API Key |
| `TO_EMAIL` | 接收邮件的邮箱 |
| `FROM_EMAIL` | 发件邮箱 |
| `FEISHU_WEBHOOK` | 飞书机器人 Webhook |

### 2. 定时运行

默认每天 **UTC 00:30（北京时间 08:30）** 自动运行，无需任何操作。也可在 Actions 页手动触发。

### 3. 本地调试

```bash
pip install -r requirements.txt
cp .env.example .env  # 填入你的配置
python daily_news.py
```
